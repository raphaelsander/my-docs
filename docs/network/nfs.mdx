## O que é NFS?

**NFS** (**N**etwork **F**ile **S**ystem) é um protocolo que permite acesso remoto
a um sistema de arquivos através da rede. O cliente NFS torna o acesso remoto transparente
para o usuário, fazendo com que arquivos e diretórios remotos pareçam estar acessados
localmente.

### NFS vs SMB/Samba

- **NFS**: Protocolo nativo de sistemas Unix/Linux. Melhor desempenho para ambientes
  Unix.
- **SMB/CIFS**: Protocolo usado principalmente por sistemas Windows. Necessário
  quando Windows está envolvido.

## Verificar Compartilhamentos Disponíveis

Para listar os compartilhamentos NFS disponíveis em um servidor remoto, use o comando
`showmount`:

```bash
$ showmount -e 192.168.0.100
Export list for 192.168.0.100:
/var                      *
/home                     *
/mnt/dados                192.168.0.0/24
```

### Opções de `showmount`

- `-e`: Mostra a lista de compartilhamentos exportados
- `-a`: Mostra clientes conectados
- `-d`: Mostra diretórios exportados

## Montar um Compartilhamento NFS

### Preparar o Ponto de Montagem

```bash
$ mkdir -p /mnt/nfs
```

### Montar o Compartilhamento

Forma básica:

```bash
$ mount -t nfs 192.168.0.100:/var /mnt/nfs
```

Com opções de segurança e confiabilidade:

```bash
$ mount -t nfs 192.168.0.100:/ /mnt/nfs -o nolock
```

### Opções de Montagem Comuns

| Opção | Descrição |
|:-------|:-----------|
| `nolock` | Desabilita file locking (útil para compatibilidade) |
| `hard` | Continua tentando em caso de falha (padrão) |
| `soft` | Abandona após várias tentativas |
| `timeo=600` | Timeout em decisegundos (60 segundos) |
| `retrans=3` | Número de retransmissões |
| `ro` | Montagem somente leitura |
| `rw` | Montagem leitura/escrita (padrão) |

### Exemplo com Múltiplas Opções

```bash
$ mount -t nfs 192.168.0.100:/var /mnt/nfs -o nolock,hard,timeo=600,retrans=3
```

## Acessar Arquivos Montados

Após montar o compartilhamento, você pode acessar os arquivos normalmente:

```bash
$ cd /mnt/nfs
$ ls -la
total 48
drwxr-xr-x  5 root root  4096 Aug 16 10:30 .
drwxr-xr-x 10 root root  4096 Aug 16 09:15 ..
-rw-r--r--  1 root root   256 Aug 15 14:22 arquivo.txt
drwxr-xr-x  3 user user  4096 Aug 10 11:05 backup
```

## Desmontar Compartilhamento

Para desmontar um compartilhamento NFS:

```bash
$ umount /mnt/nfs
```

Forçar desmontagem (se houver travamentos):

```bash
$ umount -f /mnt/nfs
```

Desmontar mesmo com arquivos abertos:

```bash
$ umount -l /mnt/nfs
```

## Verificar Montagens Ativas

Para ver os compartilhamentos NFS montados:

```bash
$ mount | grep nfs
192.168.0.100:/ on /mnt/nfs type nfs4 (rw,relatime,vers=4.2,...)
```

Ou usar:

```bash
$ df -h | grep nfs
192.168.0.100:/  50G   15G   35G  30% /mnt/nfs
```

## Erros Comuns

### "Permission denied"
Verifique as permissões no servidor NFS e se o firewall não está bloqueando a porta
2049.

### "Stale NFS file handle"
O servidor pode ter sido reiniciado. Desmonte e remonte o compartilhamento.

### "Connection timed out"
Verifique a conectividade de rede e se o servidor NFS está ativo.
