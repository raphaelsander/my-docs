O comando `service` é utilizado para gerenciar serviços do sistema no Linux, permitindo
iniciar, parar, reiniciar e verificar o estado de *daemons* de forma simples.

---

## Uso Básico

Listar todos os serviços disponíveis:

```bash
service --status-all
```

Verificar o estado de um serviço:

```bash
service ssh status
```

Iniciar um serviço:

```bash
service ssh start
```

Parar um serviço:

```bash
service ssh stop
```

Reiniciar um serviço:

```bash
service ssh restart
```

## Gerenciamento de Inicialização

Ativar um serviço para iniciar junto com o sistema:

```bash
update-rc.d ssh enable
```

Desativar um serviço da inicialização:

```bash
update-rc.d ssh disable
```

:::info
Em sistemas mais modernos, o comando `systemctl` costuma ser a alternativa recomendada
para o gerenciamento de serviços.
:::
